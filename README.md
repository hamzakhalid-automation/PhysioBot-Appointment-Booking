# 📅 PhysioBot – Automated Appointment Booking

An AI-powered booking assistant built with **n8n** that lets physio therapy clinic patients check availability, book, and reschedule appointments anytime, without calling the front desk.

---

## 🔥 Features

- 24/7 automated appointment booking through chat
- Real-time calendar availability checking
- Automatic booking confirmation and reminders
- Reduces no-shows with automated reminders
- Frees up front-desk staff from manual scheduling calls

---

## 💼 Tech Stack

- n8n (workflow automation)
- Google Calendar API
- JavaScript (custom code nodes)
- Webhook & REST API integrations

## ⚙️ How It Works

1. Patient starts a conversation through the connected messaging channel.
2. The bot checks the clinic's calendar for available slots in real time.
3. Once the patient picks a time, the system books the appointment and sends a confirmation.
4. Automated reminders are sent before the appointment to reduce no-shows.
